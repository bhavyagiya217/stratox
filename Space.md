# Stratox ☁️
**Enterprise Cloud FinOps & DevSecOps Engine**

## Objective
To build a "shift-left" infrastructure intelligence platform that scans cloud environments and Terraform/IaC code pre-deployment to predict costs, eliminate zombie resources, and enforce security guardrails.

## Project Links
* **Live App URL:** https://stratox-psi.vercel.app
* **GitHub Repository:** https://github.com/bhavyagiya217/stratox
* **Pull Request:** https://stratox-psi.vercel.app

## Tech Stack & Tools
* **Frontend:** Next.js 14, Tailwind CSS, Lucide React
* **Backend:** FastAPI (Python), Uvicorn
* **AI Provider:** Google Gemini API (gemini-3.8-flash & 3.5-flash-lite)
* **Deployment:** Vercel (Frontend) & Localhost (Backend)

## System Workflow
`User Input (Next.js UI)` ➔ `REST POST Request` ➔ `FastAPI MoE Router` ➔ `Google Gemini API` ➔ `FinOps/Architecture Data` ➔ `Next.js Dashboard Rendering`
