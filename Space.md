# Stratox Workspace Architecture & Topology

## Workspace Definition
Specifications for organizational workspaces, role-based access control (RBAC), and multi-tenant cloud telemetry in Stratox.

## Environments
- **Production Org (Admin Workspace):** Real-time FinOps monitoring, live API failover, and active cost tracking.
- **Staging / Dev Sandbox:** Pre-flight Terraform scans and ephemeral infrastructure testing.
